# MT-Hybrid-Impedance
Code for robust MT tensor impedance estimation with RMD, FRB and VWC.
# 
This study was conducted based on the open-source software Resistics 0.0.6.

Resisitcs 0.0.6 address:https://github.com/resistics/resistics

Because the original code is not fully compatible with Phoenix magnetotelluric (MT) time-series files,
we modified and rewrote the relevant components to read low-frequency Phoenix time-series recordings.
