# MT-Hybrid-Impedance
Code for robust MT tensor impedance estimation with RMD, FRB and VWC.
# 
This study was conducted based on the open-source software Resistics 0.0.6.

To install Resistics 0.0.6: python -m pip install resistics
#
After installing resistics, replace the installed package with the version provided in this repository (e.g., replacement path: D:\Anaconda\Lib\site-packages\resistics).

Because the original code is not fully compatible with Phoenix magnetotelluric (MT) time-series files,we modified and rewrote the relevant components to read low-frequency Phoenix time-series recordings.
